## References and original links

The following references were listed in the source PDF. The official manuals should be consulted for exact syntax and current behaviour.

### 1. IBM — What is Debugging?

Overview of debugging, why it matters, and a general debugging workflow.

<https://www.ibm.com/think/topics/debugging>

### 2. GNU Project — GDB Documentation

Official reference manual for GDB commands, concepts, and debugger behaviour.

<https://sourceware.org/gdb/current/onlinedocs/gdb.html/>

### 3. GNU Project — Starting Your Program (GDB)

Official documentation on starting and controlling a program in GDB.

<https://sourceware.org/gdb/current/onlinedocs/gdb.html/Starting.html>

### 4. GCC — Debugging Options

Official GCC documentation for generating and controlling debugging information, including the `-g` option.

<https://gcc.gnu.org/onlinedocs/gcc/Debugging-Options.html>

### 5. Marc Haisenko — GDB Cheat Sheet (PDF)

A compact command reference for common GDB operations.

<https://darkdust.net/files/GDB%20Cheat%20Sheet.pdf>
